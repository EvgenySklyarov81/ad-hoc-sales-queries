> 📌 **Контекст проекта:** Практический кейс по выполнению оперативных (ad-hoc) запросов к данным о продажах. Проект реализован в среде Google Colab на базе симулированных CSV-датасетов. Направлен на демонстрацию навыков быстрой фильтрации, агрегации, визуализации и извлечения бизнес-метрик с помощью Python.
